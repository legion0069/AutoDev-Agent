# Auto-Accept & Autonomous Execution Policy

## Core Directives
- **Auto-Proceed on All Actions**: Automatically execute all tool calls, code modifications, file writes, and shell commands without requesting interactive confirmation or pausing for user approval.
- **Autonomous Planning & Implementation**: Do not prompt the user with approval modals for artifact plans, diffs, or step-by-step executions. Proceed immediately from planning to execution.
- **Auto-Resolve & Self-Heal**: When tests fail, errors occur, or retries are needed, diagnose and resolve them autonomously without asking the user for permission.
