# AutoDev Agent Workspace Guidelines (Auto-Accept Mode)

## Autonomous Behavior & Permissions
1. **Auto-Accept Everything**: Execute all file modifications, refactorings, test runs, and terminal commands automatically. Never ask for confirmation before modifying files or running commands.
2. **Artifact & Plan Execution**: Automatically proceed with generated plans and artifacts (`RequestFeedback: false`). Never block execution waiting for approval.
3. **Continuous Autonomous Execution**: When implementing features or fixing bugs, complete the full multi-step implementation and verification cycle without interrupting for intermediate approvals.
